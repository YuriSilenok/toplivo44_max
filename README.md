# Сценарии использования топливного MAX-бота для Костромского региона

---

## Роль: Водитель

| Действие пользователя | Ответ системы |
|---|---|
| Запускает чат-бота | Бот приветствует. Показывает меню роли «Водитель»: только кнопка «Найти топливо». Остальные кнопки не отображаются. |
| Нажимает «Найти топливо» | Бот предлагает отправить координаты кнопкой «Отправить мои координаты» и выбрать марку топлива кнопками: «АИ-92», «АИ-95», «ДТ», «АИ-98». Все кнопки марок — в нейтральном цвете. |
| Нажимает «Отправить мои координаты» | Бот принимает координаты и просит выбрать марку топлива. Кнопки марок остаются в нейтральном цвете. |
| Нажимает одну из марок, например «АИ-95» | Кнопка «АИ-95» меняет цвет на зелёный (выбрана). Бот выполняет поиск. <br><br>**Варианты ответа:** <br><br>**1. Есть свежие подтверждённые данные и АЗС с координатами.** <br>Бот показывает до трёх ближайших АЗС. Для каждой АЗС указаны: адрес, очередь в минутах, время передачи информации и ссылка «Открыть на карте». <br>Пример: <br>«Нашёл подходящие АЗС для марки АИ-95:<br>1. г. Кострома, ул. Советская, д. 1<br>Очередь: 10 минут<br>Информация передана: 14:05<br>Открыть на карте: https://yandex.ru/maps/?pt=40.926,57.767&z=17&l=map» <br>В ответе нет отдельной широты и долготы. <br><br>**2. Подходящих АЗС больше трёх.** <br>Бот показывает только три ближайшие. Более далёкие АЗС в ответ не попадают. <br><br>**3. Нет свежих подтверждённых данных ни от оператора, ни с портала.** <br>Бот отвечает нейтрально: <br>«Сейчас нет актуальной информации о наличии этого топлива. Попробуйте уточнить позже.» <br><br>**4. Все операторы по этой марке отметили «Нет».** <br>Бот не показывает такие АЗС. Если других АЗС с этой маркой нет — отвечает тем же нейтральным сообщением. <br>Запрещены формулировки «топлива нет», «отсутствует», пустой список, ошибка. <br><br>**5. Портал недоступен, но есть последние сохранённые свежие данные.** <br>Бот показывает подходящие АЗС по этим сохранённым данным. |
| Пытается вручную вызвать «Обновить сведения» | Бот отвечает отказом: <br>«Это действие доступно только оператору.» <br>Данные оператора не открываются. |

## Роль: Оператор

| Действие пользователя | Ответ системы |
|---|---|
| Запускает чат-бота | Бот приветствует. Показывает меню роли «Оператор»: кнопки «Найти топливо» и «Обновить сведения». Кнопки «Добавить АЗС», «Добавить роль», «Удалить роль» не отображаются. |
| Нажимает «Найти топливо» | Бот работает так же, как для водителя: предлагает отправить координаты и выбрать марку. Далее показывает до трёх ближайших АЗС или нейтральный ответ — как в сценарии водителя. |
| Нажимает «Обновить сведения» | Бот начинает последовательный опрос марок топлива его АЗС. <br>Показывает первую марку, например «АИ-92», и две кнопки: <br>• «Есть» — зелёного цвета; <br>• «Нет» — красного цвета. |
| Нажимает «Есть» для текущей марки | Кнопка «Есть» становится зелёной (активной). Бот предлагает выбрать очередь кнопками: «0», «5», «10», «15», «20», «Более 30». Все кнопки очереди — в нейтральном цвете. |
| Выбирает очередь, например «10» | Кнопка «10» становится зелёной (выбрана). Бот сохраняет сведения и отвечает: <br>«Сведения сохранены: АИ-92 — есть, очередь 10 минут, время передачи 14:05.» <br>Затем бот автоматически переходит к следующей марке, например «АИ-95», и снова показывает кнопки «Есть» (зелёная) и «Нет» (красная). |
| Нажимает «Нет» для текущей марки | Кнопка «Нет» становится красной (активной). Бот сохраняет сведения и отвечает: <br>«Сведения сохранены: АИ-95 — нет. АЗС не будет показываться водителям по этой марке.» <br>Затем бот переходит к следующей марке. |
| Обрабатывает все марки по очереди | После последней марки бот отвечает: <br>«Все марки обработаны. Спасибо.» |
| В текущем часе не обновлял сведения, наступает 55 минут | Бот отправляет напоминание: <br>«Пожалуйста, обновите сведения о топливе на вашей АЗС.» <br>В напоминании есть кнопка «Обновить сведения». |
| Уже обновлял сведения в текущем часе, наступает 55 минут | Бот не отправляет напоминание. Кнопка «Обновить сведения» в напоминании не появляется. |
| Пытается вручную вызвать «Добавить АЗС» | Бот отвечает отказом: <br>«Это действие доступно только администратору.» <br>Форма добавления АЗС не открывается. |

## Роль: Администратор

| Действие пользователя | Ответ системы |
|---|---|
| Запускает чат-бота | Бот приветствует. Показывает меню роли «Администратор»: кнопки «Найти топливо», «Обновить сведения», «Добавить АЗС», «Добавить роль», «Удалить роль». |
| Нажимает «Найти топливо» | Бот работает так же, как для водителя: предлагает координаты и марку, показывает до трёх АЗС или нейтральный ответ. |
| Нажимает «Обновить сведения» | Бот работает так же, как для оператора: последовательно показывает марки АЗС, кнопки «Есть» (зелёная) / «Нет» (красная), сохраняет очередь или отсутствие топлива. |
| Нажимает «Добавить АЗС» | Бот спрашивает адрес АЗС. |
| Указывает адрес | Бот спрашивает координаты АЗС. |
| Указывает координаты, например широта 57.767, долгота 40.926 | Бот предлагает выбрать марки топлива кнопками: «АИ-92», «АИ-95», «ДТ», «АИ-98». <br>Все кнопки марок — в нейтральном цвете. <br>В конце — кнопка «Готово». |
| Нажимает на марку, например «АИ-95» | Кнопка «АИ-95» меняет цвет на зелёный (выбрана). |
| Нажимает на ту же марку повторно | Кнопка «АИ-95» возвращается в нейтральный цвет (выбор снят). |
| Выбирает нужные марки (например, «АИ-95» и «ДТ») | Выбранные кнопки становятся зелёными. Невыбранные остаются нейтральными. |
| Нажимает «Готово» | Бот создаёт АЗС и отвечает: <br>«АЗС создана: адрес — <адрес>; координаты — 57.767, 40.926; марки — АИ-95, ДТ.» <br><br>**Важно:** без координат АЗС не создаётся. Бот всегда запрашивает координаты. Пока координаты не указаны, переход к выбору марок и созданию невозможен. |
| Нажимает «Добавить роль» | Бот предлагает выбрать «Администратор» или «Оператор». |
| Выбирает роль, например «Оператор» | Бот создаёт одноразовую ссылку-приглашение и отвечает: <br>«Ссылка-приглашение создана: <ссылка>. Действует 24 часа, срабатывает 1 раз.» |
| Нажимает «Удалить роль» | Бот показывает список пользователей. |
| Выбирает пользователя | Бот просит подтверждение кнопками «Да, снять» и «Отмена». |
| Нажимает «Да, снять» | Бот снимает роль и отвечает: <br>«Роль снята. Пользователь больше не видит кнопку <название кнопки>.» |
| Нажимает «Отмена» | Бот отвечает: <br>«Удаление отменено. Роль сохранена.» <br>Меню пользователя не меняется. |
| Выбирает самого себя для удаления роли, если он единственный администратор | Бот отвечает: <br>«Нельзя снять роль с себя, если вы единственный администратор.» <br>Роль администратора сохраняется. |

## Приглашённый пользователь (получение роли)

### Действующая ссылка

| Действие пользователя | Ответ системы |
|---|---|
| Переходит по действующей одноразовой ссылке | Бот выдаёт роль, например «Оператор», и отвечает: <br>«Вы получили роль «Оператор». В меню доступны «Найти топливо» и «Обновить сведения».» |

### Просроченная ссылка

| Действие пользователя | Ответ системы |
|---|---|
| Переходит по ссылке, созданной более 24 часов назад | Бот отвечает: <br>«Ссылка-приглашение просрочена. Попросите администратора создать новую.» <br>Роль не выдаётся. |

### Использованная ссылка

| Действие пользователя | Ответ системы |
|---|---|
| Переходит по ссылке, которая уже была использована | Бот отвечает: <br>«Эта ссылка уже использована. Попросите администратора создать новую.» <br>Роль не выдаётся. |
