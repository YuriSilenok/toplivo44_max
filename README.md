# Топливный навигатор MAX

Бот: https://max.ru/fuelmap_digitalkostroma_bot

По геолокации и марке топлива показывает до трёх ближайших АЗС с подтверждённым наличием по последним сведениям оператора или портала https://toplivo.kostroma.gov.ru/.

## Поиск и источник

1. Нажмите «Найти топливо», отправьте геолокацию и выберите АИ-92, АИ-95 или ДТ.
2. Бот сортирует подходящие АЗС по расстоянию и выдаёт до трёх карточек: название, адрес, марка, опубликованная цена, очередь, ограничения, дата источника и Яндекс.Карты.
3. Используются последние сохранённые сведения **без ограничения возраста одним часом**. Дата источника показывается всегда; после часа добавляется предупреждение о возможном изменении наличия. Новое отсутствие топлива не заменяется старым положительным состоянием.
4. Если подходящих сведений нет, бот сообщает об отсутствии АЗС с подтверждённым наличием в последних полученных данных оператора или портала. Это не утверждение, что топлива нигде нет.

Основной источник — карта DataLens, чарт `1mfpck09rnyck`: POST `https://datalens.yandex/charts/api/run`. Загрузка запускается после старта службы, далее через 300 секунд после завершения предыдущего цикла. Дата загрузки не подменяет дату обновления источника.

Ненулевая опубликованная цена означает наличие; нулевая или отсутствующая — отсутствие подтверждённого наличия. «Нет» в поле очереди означает отсутствие очереди. Ограничение «Да» — лимит объёма в одни руки за одну заправку; точный объём уточняется на АЗС.

Полученные записи с некорректной или слишком далёкой будущей датой пропускаются с сохранением предыдущих сведений. Более ранние записи не затирают более поздние. Реестр содержит 81 АЗС; число записей определяется источником.

## Сбои источника и уведомления

При недоступности портала используются последние сохранённые сведения с датой источника. До уведомления администраторам выполняются три последовательные попытки с паузой 5 минут (первая загрузка и два повтора). После этого загрузка продолжается с той же паузой; повторное уведомление — не чаще одного раза в час каждому администратору. Успешная загрузка сбрасывает счётчик ошибок; состояние переживает перезапуск.

Сообщение содержит источник, тип ошибки/HTTP-код, число неудач, первую и последнюю ошибку и последнее успешное получение. При наличии выводятся Content-Type, Retry-After и краткое безопасное описание источника. Полные ответы, токены и cookies в уведомления не включаются. HTTP 427 сам по себе не доказывает превышения частоты запросов; `ERR.CHARTS.DATA_FETCHING_ERROR` — общий сбой получения данных чарта.

## Роли и работа со сведениями

- Любой пользователь ищет топливо и сообщает об ошибке через «Нашли ошибку?» → «Топлива нет» / «Топливо есть». Сообщение идёт привязанным к АЗС операторам, при их отсутствии — администраторам. Повторы по одной АЗС и марке ограничены 5 минутами. Сообщение водителя само не изменяет наличие.
- Оператор получает напоминания и обновляет сведения по привязанным АЗС через «Обновить сведения». Администратор может обновлять любую АЗС.
- Администратор добавляет АЗС, привязывает операторов, создаёт приглашения и управляет ролями. Приглашение действует 24 часа и используется один раз. При приглашении оператора выбирается АЗС.

При добавлении АЗС запрашиваются адрес, координаты и марки. Такая запись появляется в поиске при положительных сведениях оператора или сопоставленных сведениях портала.

## Устаревшие сведения

Для оператора порог — более часа по привязанным АЗС; для администратора — более двух часов по всем АЗС (по привязанным действует также часовой порог). Напоминание одному получателю отправляется не чаще часа, одним сообщением с тремя самыми давно обновлёнными АЗС и временем последнего обновления в МСК.

«Показать все» редактирует это же сообщение: список идёт от давних обновлений к свежим, кнопка раскрытия убирается. При превышении длины сообщения появляются «Назад» / «Далее». Список пересчитывается на момент нажатия.

## Реализация и запуск

Рабочая версия включена в каталог `src/` этого репозитория. Это общий код трёх приложений; для данного бота укажите `BOT_KIND=fuel`. Каждое приложение запускается отдельным процессом с собственной БД и конфигурацией. Описание переменных окружения, запуска и обслуживания: [запуск и обслуживание](docs/runtime.md).

Стек рабочей версии: Python 3.12 на VDS, aiohttp, Peewee, SQLite. События поступают через HTTPS webhook MAX; входящие события и исходящие сообщения сохраняются в SQLite. Диалоги хранятся в БД, срок состояния — 10 минут. `/start` сбрасывает текущий диалог, `/id` показывает MAX ID, «Отмена» отменяет текущий ввод.

Роли проверяются перед действиями; права выдаются одноразовыми приглашениями либо администратором сервера через `manage.py`. Последнюю роль администратора снять через меню нельзя. Секреты и рабочие БД в Git не сохраняются.

Тесты и пробные обращения в ботов по указанию владельца не запускаются.

## Структура репозитория

- src/ — рабочий Python-код и публичная цепочка сертификатов портала.
- deploy/ — скрипты существующего VDS.
- docs/ — документация эксплуатации.
- requirements.txt — закреплённые зависимости рабочей версии.
- .env.example — шаблон конфигурации без секретов.

Установка: python -m pip install -r requirements.txt. После загрузки настроек в окружение: python -B src/app.py. Файл .env автоматически не загружается. Для 'fuel' используйте BOT_KIND=fuel. Текущие данные хранятся в data/ и не включаются в Git.

## Карта всех точек

Кнопка «Карта всех точек» открывает карту с реестром, поиском по адресу/названию и выбором трёх ближайших по геолокации. В топливной карте можно выбрать марку топлива; дата источника и предупреждения об устаревших сведениях сохраняются. Исходный поиск в диалоге бота также доступен. Карта включается параметром `MAP_ENABLED=1`. Развёртывание описано в [документации](docs/runtime.md#развёртывание).
## Ввод сведений оператором

«Обновить сведения» → ID АЗС из доступного списка → для каждой марки «Есть» / «Нет». При «Есть» указывается очередь: 0, 5, 10, 15, 20 или более 30 минут. Каждая завершённая марка сохраняется сразу с текущим временем МСК. «Отмена» прекращает ввод; уже сохранённые марки остаются. Диалог истекает через 10 минут. Оператор видит только привязанные АЗС; перед каждым сохранением права проверяются повторно. Администратору доступны все АЗС.

Данные портала и оператора хранятся раздельно. Для каждой АЗС/марки выбирается более поздняя запись независимо от наличия; при равных датах приоритет у оператора. Более свежее «Нет» исключает АЗС из поиска по этой марке, а новое «Есть» возвращает. Поиск и карта используют один алгоритм. Данные оператора помечены источником, устаревшая цена портала к ним не подставляется; ограничения портала остаются отдельно обозначенными сведениями портала. Напоминания учитывают обновления обоих источников. Обратной записи в портал нет.


### Карта на телефоне

В вертикальной ориентации карта расположена над списком, поля и кнопки переносятся по ширине экрана. В горизонтальной ориентации карта и прокручиваемый список показаны рядом, шапка компактная. При повороте экрана размеры карты и высота всплывающей карточки пересчитываются автоматически. Фильтры и поиск сохраняются при повороте.
